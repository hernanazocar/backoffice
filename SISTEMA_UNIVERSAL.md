# 🌍 Sistema Universal - Para CUALQUIER Industria

## 🎯 **El Concepto**

**El mismo sistema de agentes IA se adapta a CUALQUIER negocio:**

- Software SaaS → Agentes hablan de features, trials, demos
- Ferretería → Agentes hablan de stock, proveedores, herramientas
- Restaurante → Agentes hablan de menú, reservas, deliverys
- E-commerce → Agentes hablan de productos, carrito, envíos

**Los agentes son los mismos. El conocimiento cambia.**

## 🏭 **8 Templates de Industria Incluidos**

### 1. 💻 **Software / SaaS**
**Ejemplo:** Empresa de software de gestión contable

**Áreas activas:**
- Marketing (contenido técnico, demos, casos de éxito)
- Ventas (inside sales, trials, onboarding)
- Producto (desarrollo, bugs, features)
- Atención Cliente (soporte técnico, documentación)

**Agente Analista de Marketing busca:**
- ✅ Qué features promocionan los competidores
- ✅ Tendencias en software contable
- ✅ Precios de planes competencia

**Workflow típico:**
- Crear contenido técnico sobre nueva feature
- Generar casos de éxito de clientes
- Campañas para trials gratuitos

## 🔧 **Implementación Técnica**

### **Los agentes leen el contexto:**

```python
# System prompt del Analista se adapta automáticamente

if industria == "restaurante":
    context = """
    Eres analista de un restaurante.
    Enfócate en: menú, precios, reseñas, competencia local.
    Analiza: Google Reviews, Instagram de competidores, portales food.
    """

elif industria == "software":
    context = """
    Eres analista de una empresa de software.
    Enfócate en: features, pricing, casos de éxito, integraciones.
    Analiza: sitios web, blogs técnicos, G2, Capterra.
    """
```

**El agente se comporta diferente según la industria.**
